The Foundation

I came into tech with a single question that wouldn't leave me alone: how do attackers actually get in? That question led me to Moringa School's cybersecurity program — not to collect a certificate, but to get real answers. I left knowing how systems fail, which turned out to be the most valuable thing I could know about building them.

What Moringa gave me was structure. What came after was the education that actually mattered: building real products under real constraints, hunting bugs that existed in production systems, and solving problems that textbooks don't cover.

The Builder Mindset

I don't build tutorials. I build things that run. SPACE-Y is a live social platform with 80+ active users. MshindiSecure is a toolkit companies can deploy to harden their login systems. These aren't portfolio projects — they're engineering decisions I made, shipped, and defend.

I discovered early that the gap between knowing how to code and knowing how to build is enormous. One teaches you syntax. The other teaches you to think about systems: what happens when a user abuses a form, when traffic spikes, when someone with Burp Suite decides your login page looks interesting.

Security as Architecture

Most developers think about security after the feature is done. I think about it at the design stage — before the first endpoint is written. What data does this route expose? How does session invalidation work? What happens if someone replays that token?

This isn't caution. It's efficiency. Retrofitting security is expensive and often incomplete. Building it in is cheaper, tighter, and produces code I'm not embarrassed by six months later when someone tries to break it.

Continuous Sharpening

TryHackMe keeps my offensive skills current. Bug bounty hunting trains my eye for the non-obvious — the logic flaws, the edge cases, the authorization bypasses that automated scanners miss. I run security mentorship sessions to solidify my own knowledge through teaching it.

I also take AI seriously as a tool, not a substitute. I use it to accelerate boilerplate, to review patterns, to brainstorm attack surfaces. The judgment call is still mine. The architecture is still mine. AI just means I get to spend more time on the hard problems.
